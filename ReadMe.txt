Now you can use any web page, HTML file, Shockwave Flash animation*, PDF file*, JPEG image, or any other file type supported by Internet Explorer as a screen saver.

You could set it to your favourite news or financial web site so that you have the latest headlines or share prices when you return to your desk.

Businesses, you could use it so that idle PCs display your intranet site, or even a PowerPoint presentation of your latest product.


System requirements
-------------------
Windows 2000 or later with Microsoft Internet Explorer version 5.0 or later.

Installation
------------
If you installed this program from the MSI file using Windows Installer, you do not need to read this section.

If you downloaded the ZIP file, please follow these instructions:

For best results, copy the file sshtml.scr to your Windows root directory (e.g. C:\Windows). It will then automatically be found by the Display properties dialog and listed in the Screen Saver combo box.

Alternatively, copy it to any other location (e.g. C:\Program Files\HTML Screen Saver), right click on the file sshtml.scr from within Windows Explorer and select the Install command from the popup menu. This will make the HTML Screen Saver the active screen saver. However, if you later select a different screen saver, the HTML Screen Saver might no longer be listed in the Display properties dialog. You may have to find the file sshtml.scr and run the Install command each time you want to make this the active screen saver.

Use
---
Use the Display control panel applet, Screen Saver tab, to select and configure the screen saver. In the configuration dialog, enter or browse for a URL or file that you want displayed when the screen saver activates. The configuration dialog is sizeable so you can stretch it to see the full path of the URL or file chosen. Each user on the computer can choose their own URL or file.

If you tick 'Remove border and scrollbars', the screen saver will not have the border or vertical scrollbar that normally appear. This feature is optional because you might need to be able to scroll the window.

If your computer has more than one monitor, you can choose what to display on each one. In 'Display', select each display in turn and select a URL and a border and scrollbars option for each one.

If you tick 'Toggle Caps Lock to keep screen saver active', when the screen saver is running if you press the Caps Lock key the screen saver will stay active when you use the mouse or keyboard. This allows you to click on hyperlinks, for example. When you want to deactivate the screen saver, press the Caps Lock key again and then move the mouse or press any other keyboard key. This feature is optional because you might not want people to be able to interact with the screen saver.

If you tick 'Disable context (right-click) menu', when you click the right mouse button or press the Windows menu key, the context menu will not appear. This increases security by preventing people from interacting with the browser while allowing them to interact with the content. This feature is optional because you might want to allow the context menu, e.g. to print or to navigate back.


Uninstallation
--------------
If you installed the program using Windows Installer, you must change your active screen saver to something else before uninstalling, otherwise Windows Installer may leave the file sshtml.scr on your disk and not warn you that it was not removed.

Known issues
------------
Windows 95 password mode (command line parameter /a) is not supported. This is not required for Windows 2000 or later.
